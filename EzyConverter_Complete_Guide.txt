================================================================================
                            WHAT IS EZY CONVERTER?
================================================================================

EzyConverter is a modern, privacy-first conversion platform that brings multiple
converters together in one sleek interface. It enables users to convert:

1. IMAGE FILES (PNG, JPG, WebP)
2. PDF FILES (Merge, Compress)
3. UNIT CONVERSIONS (Temperature, Length, Weight, Time, Data, Engineering, Math)

The key differentiator: ALL processing happens entirely in your browser.
Files never leave your device, no accounts needed, and the tool works offline
after the initial page load.

================================================================================
                         HOW CONVERTERS WORK (3 STEPS)
================================================================================

STEP 1: DROP YOUR FILES / ENTER VALUE
   • For file converters: Drag and drop files or click to browse
   • For unit converters: Enter a number value in the input field
   • Select the source unit from the "From" dropdown

STEP 2: CHOOSE OPTIONS
   • For files: Select output format and quality settings
   • For units: Select the target unit from the "To" dropdown
   • Adjust precision/quality sliders as needed

STEP 3: DOWNLOAD RESULTS
   • For files: Download individual files or get a ZIP archive
   • For units: Copy the result or download conversion table
   • Results appear instantly (no waiting)

================================================================================
                            CORE FUNCTIONALITY
================================================================================

IMAGE CONVERSION PROCESS:
  1. User selects image files via drag-drop or file browser
  2. Preview thumbnails display for each file
  3. User selects output format (WebP, JPG, or PNG)
  4. User adjusts quality slider (1-100%, hidden for PNG)
  5. Application converts files client-side using Canvas API
  6. Original and converted file sizes shown
  7. Compression percentage calculated and displayed
  8. User downloads individually or as ZIP archive

PDF OPERATIONS PROCESS:
  1. User uploads PDF files (up to 50 MB each)
  2. Selects operation mode (Merge or Compress)
  3. For Merge: Combines multiple PDFs into single file
  4. For Compress: Reduces file size while maintaining quality
  5. Results available for download

UNIT CONVERSION PROCESS:
  1. User enters a numeric value
  2. Selects "from" unit and "to" unit
  3. Real-time conversion calculation
  4. Conversion formula displayed
  5. Precision adjustable (0-10 decimal places)
  6. Results copied with one click
  7. Conversion history tracked
  8. Dynamic conversion tables generated
  9. Related conversions suggested

SHARED FEATURES ACROSS ALL CONVERTERS:
  • Conversion History - Recent conversions stored and displayed
  • Dynamic Tables - Conversion tables generated on-the-fly
  • Educational Content - Learn more sections with unit explanations
  • SEO Content - Optimized for search engines
  • Popular Conversions - Quick-access links to common conversions
  • Decimal Precision - Adjustable decimal places (0-10)
  • Copy & Share - One-click copy and URL sharing
  • Mobile Responsive - Works perfectly on mobile devices

================================================================================
                        INSTALLATION & SETUP
================================================================================

REQUIREMENTS:
  • Node.js (latest LTS recommended)
  • npm or yarn package manager
  • Modern web browser

INSTALLATION STEPS:
  1. Clone the repository
  2. Navigate to project directory: cd ezyconverter
  3. Install dependencies: npm install
  4. Start development server: npm run dev
  5. Open browser to http://localhost:5173

BUILD FOR PRODUCTION:
  npm run build
  npm run preview

DEPLOYMENT:
  • Can be deployed to any static hosting service
  • Lovable platform integration available
  • Custom domain support
  • GitHub integration for auto-deployment
